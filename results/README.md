# Results

Generated by `python3 exp/paper_export.py` from `results/<exp>/*.json`. One sub-folder per experiment.

**Start with [`tables/`](tables/README.md)**: `tables/0_paper_tables.md` reproduces every table and figure of the paper from the CSVs here, under the paper's rules; tables 1–10 are the extended views. The per-experiment folders below are the raw data behind them.

Every folder has `runs.csv` (one row per run) and `summary.csv` (one row per design × variant, mean and half-range over seeds). Columns of `runs.csv`:

| column | meaning |
|---|---|
| `hpwl_global` | HPWL (µm) as left by the placer, before legalization |
| `hpwl_dpl` | HPWL after `detailed_placement`, before DPO — **the primary metric** in E12 onwards |
| `hpwl` | final HPWL: after `improve_placement` (DPO) where `dpo` = 1, else = `hpwl_dpl` |
| `grt_wl`, `overflow`, `max_overflow_h/v` | `global_route` wirelength (µm, GRT-0018) and the `Total` line of the final congestion report (GRT-0096); empty when not routed. GRT-0018 divides by the block's DEF units, so `grt_wl` is 10× too large for the ASAP7 checkpoints of aes, gcd, jpeg and swerv (DEF units 100, 1000 dbu/µm); `exp/grt_tables.py` corrects it, ratios on one floorplan are unaffected |
| `wns`, `tns` | post-route STA (ns); empty when no liberty / not routed |
| `t_place`, `t_dpl`, `t_dpo`, `t_grt`, `t_total` | seconds, 4 threads unless `threads` says otherwise |
| `mem_peak_mb` | peak RSS of the OpenROAD process |
| `violations` | legalizer check violations (0 = legal) |
| `routing` | `ok`, `not run` / `skipped (MCP_NO_ROUTE)`, or `failed: <code>` |
| `options` | the mcp option string of the variant (empty for gpl / capo) |
| `kind` | `gpl`, `capo`, `mincut`, … — the placer family |

Older grids (E0–E11) ran without DPO: `hpwl` = `hpwl_dpl` there. Where a grid has its own wide table or ratio summary (E17, E25, X4, hybridization), it is copied alongside; `summary_runs_legacy.csv` is the grid's original `exp/summarize.py --csv` export where one existed.

Placer codes used in the `variant` column: `gpl` = RePlAce (OpenROAD `global_placement`); `capo` = Capo 10.5; `tp` / `hm` / `mk` / `fp` = RB with TritonPart / hMETIS / Mt-KaHyPar / FastPart; `cutnet_tp` = RB (TP) (same configuration as `tp`, in the `x3_mega` / `x4_ar_sweep` grids); `kway_tp` = RB+k (TP). Other variant names are experiment-specific and explained in the folder's `STATUS.md` or in the table that uses them.

## Failure accounting files

* `x3_mega/replace_convergence.csv`, `e23_base/replace_convergence.csv`, `x4_ar_sweep/replace_convergence.csv`: per RePlAce run (floorplan, seed), what its log reported — final density overflow, iterations, whether it hit the 5000-iteration cap, diverged or failed legalization — and the resulting `converged` flag (1 = stopped at or below the 0.2 overflow target and legalized). A RePlAce run with `converged` = 0 is a failure in the paper; `0_paper_tables.md`, tables 7–9 apply this rule (137 of the 180 few-row floorplans remain), tables 1–6 use the weaker condition that RePlAce produced a legal placement (149).
* `e17_krow/rb_engine_reports.csv`, `e23_base/rb_engine_reports.csv`: per RB run, how many bisections the partitioner failed to return (the placer's FM fallback stood in), whether the root bisection failed, the resulting `verdict` (`ok`, `kept` = sporadic fallback below 1 % of the bisections, `fail` = root or > 1 % failed — excluded in the paper), the cause, and the root / total cut counts behind the cut rows of Table II.

## Notes

* `e23_base`: megaboom and mempool_group were placed but not routed (FastRoute ran for days). The `fp` (FastPart) arm on xiangshan_ar1_nangate45, megaboom (both PDKs) and mempool_group is not a FastPart result: the engine's worker processes died at start-up and every region fell back to FM (`verdict` = `fail` in `rb_engine_reports.csv`); it is excluded from every aggregate.
* `x4_ar_sweep`: `replace_baseline_floorplan_author.csv` is the floorplan author's own RePlAce (`-routability_driven`) summary for the floorplans he had finished (ar0.03_util60); not used in the paper.
* `x3_mega` is the grid of `exp/x3_mega.cfg`; one stray `gpl_dia` run is a probe.
* `gpl` is deterministic; its seeds 1–3 are identical runs where present.
